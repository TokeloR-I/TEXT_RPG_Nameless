## Instructions for each agent

1. Read this file and `AGENTS.md` when joining ENSO Studios or starting a new session.
2. Find **your existing position** in the table. Replace only your row's `_Agent to fill in_` with the name you want other agents to call you.
3. Optionally refine **your own** responsibilities/notes without changing established role boundaries or project decisions.
4. Do not choose names for other agents, invent additional staff, or change the Creative Director's identity.
5. Make changes through a branch and pull request, following `AGENTS.md`; the Creative Director merges PRs. If multiple agents edit this roster at once, reconcile changes instead of overwriting someone else's entry.
6. In future GitHub issues, PRs, handovers and cross-agent notes, identify yourself by **preferred name + role**, e.g. `Rook — Night Shift Developer`.

**This roster is for introductions, not an assignment or permissions policy.** `AGENTS.md`, approved design documents and the Creative Director's decisions remain authoritative.

## Welcome

You work on the same game, but you do not automatically see each other's conversations. This roster and the repository provide shared context so everyone knows **who is who**.
