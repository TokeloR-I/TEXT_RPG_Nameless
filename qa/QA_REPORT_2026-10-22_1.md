# QA Report 2026-10-22 #1 — build 2026-10-22.1 (status engine)

## Summary
- **Build health: good.** 20/20 file hashes match the manifest, 92/92 tests pass, 4 full play-cli runs and all fuzzing produced no errors or NaN. All 21 Status Engine Report §6 claims hold under my own scenarios, and its mutation-check claim holds (4/4 rule breaks are caught).
- **Worst issue: QA-1 (major regression).** Round-based durations count the *holder's* turns, so statuses whose effect plays out on someone else's turn now depend on speed. Marked for Death does nothing against a slower target, which for the fast Rogue is nearly every enemy. QA-2: Shield Bash stun-locks the final boss for free.
- **Balance headline:** warrior 56% · mage 0% · rogue 8% · necro 2% (100 runs). A smarter bot doesn't close the gap, so it's the numbers, not the bot. At the boss, **branch choice decides the outcome** (0–100% within one class) because 4 branch resources have no regen.

## Design gaps
1. **Rule 11 for "other people's turn" effects** (QA-1): should Expose, Marked for Death, Guard, Evasion, Riposte and Taunt count the **holder's** turns (today), the **applier's** turns (pre-build), or rounds in which the effect could actually be used? The handoff says "regardless of speed", which today is only true for DoTs and turn-skips.
2. **Shield Bash's condition** reads Momentum, which the Vanguard no longer has from L3 (the level Shield Bash is learned). Oath Points ≥ 3? Drop the condition? This and CR decide whether stun-lock is possible.
3. **Base skills after branching:** keep spending the base resource (Momentum / Energy / Mana), or the new branch resource (today)? If the branch resource, Stealth Tokens, Combo Points and Deception Tokens need a gain rate the base kit can live on (the 0-regen values are marked * placeholders).
4. **Refreshing an uncapped DoT with a different value:** the latest wins today (Black Spit Poison 5, then a Poison Trap 4 → 4). Keep the latest, keep the stronger, or stack?
5. **Reactions on refresh:** re-applying a status that's already there (Bleed onto Bleed+Poison) fires the reaction again. Does a refresh count as "applying a new status" (rule 14)?
6. **Reaction chains:** may a reaction's outcome trigger another reaction? If yes, how deep (QA-4)?
7. **Control Resistance is all-or-nothing:** none of it runs until all 5 tier multipliers (incl. player and summon) are set. Once enemies get stuns, the player multiplier is what prevents player stun-lock (QA-5).
8. **Flee:** should enemies you killed stay dead, and should damage on survivors persist (QA-6)?
9. **James Newton** (666 HP / 66 DEF test dummy) is announced in the very first room with an "Engage" prompt. New players who engage die. Ship it?
